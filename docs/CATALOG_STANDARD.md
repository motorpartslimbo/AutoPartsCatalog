# AutoPartsCatalog — CATALOG_STANDARD.md

**Версия:** 1.2  
**Статус:** Действующий стандарт проекта

---

# 1. Цель проекта

Создание единого каталога автозапчастей с единым стандартом оформления для GitHub и Kaspi.

---

# 2. Структура карточки

Файлы `product.md` и `kaspi.txt` всегда имеют одинаковую структуру.

1. Название товара
2. Описание
3. Характеристики
4. Комплектация
5. Преимущества
6. OEM-номера
7. Применяемость
8. О бренде
9. Почему выбирают нас

---

# 3. Источники информации

Приоритет источников:

1. Официальный каталог производителя.
2. TecDoc (если доступен).
3. Exist.
4. Emex.
5. Другие проверенные каталоги.

Если информация отсутствует в официальном каталоге, она должна быть подтверждена минимум двумя независимыми источниками.

---

# 4. OEM-номера

Правила:

- Только подтверждённые OEM.
- FMSI, WVA, EAN и другие служебные коды не публикуются.
- OEM оформляются по маркам автомобилей.
- OEM публикуются только для тех марок, которые присутствуют в разделе «Применяемость».
- Если марка исключена из безопасного списка применяемости, её OEM также исключаются.

Порядок марок должен совпадать с разделом «Применяемость».

---

# 5. Применяемость

Правила:

- Используется только безопасный список.
- Не добавляются спорные модели.
- При необходимости указываются поколения, кузова и годы выпуска.
- В конце раздела всегда размещается рекомендация проверить совместимость по VIN или OEM.

Порядок марок полностью совпадает с разделом OEM.

---

# 6. Порядок марок

Марки располагаются в алфавитном порядке.

Пример:

- Ford
- Mazda
- Nissan
- Opel
- Renault
- Saab
- Volvo

Отсутствующие марки не выводятся.

---

# 7. Порядок внутри разделов

OEM:
- группируются по маркам;
- внутри марки сортируются по возрастанию.

Применяемость:
- группируется по маркам;
- внутри марки модели располагаются по названию;
- затем по поколению;
- затем по годам выпуска (если подтверждены).

---

# 8. Характеристики

Указываются только подтверждённые параметры, полезные покупателю.

---

# 9. Комплектация

Указывается только фактическая комплектация конкретного товара.

---

# 10. Фотографии

Обязательные изображения:

- главное фото;
- деталь;
- комплект;
- упаковка;
- заводская этикетка.

Главное фото:
- белый фон;
- фирменный стикер в левом верхнем углу;
- без изменения геометрии детали.

---

# 11. Рабочий процесс

1. Добавить товар в stock.xlsx.
2. Создать папку товара.
3. Добавить фотографии.
4. Заполнить source/links.md.
5. Передать материалы в ChatGPT.
6. Проверить характеристики.
7. Проверить OEM.
8. Проверить применяемость.
9. Подготовить product.md и kaspi.txt.
10. Проверить фотографии.
11. Утвердить карточку.
12. Commit.
13. Push.
14. Опубликовать в Kaspi.

---

# 12. Эталонная карточка

Первой карточкой стандарта AutoPartsCatalog v1.2 является:

**MK Kashiyama D3132H**

Все последующие карточки оформляются по её структуре и стилю.

---

# 13. Главное правило

Качество данных важнее количества.

Если информация не подтверждена официальным каталогом или двумя независимыми источниками, она не включается в карточку.
