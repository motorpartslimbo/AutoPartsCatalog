## Правила версий

Новая версия проекта создаётся при значимых изменениях:

- изменение структуры проекта;
- изменение шаблона карточки;
- изменение правил оформления;
- добавление новых возможностей.

Добавление новых карточек товаров само по себе не считается новой версией проекта. Версии отдельных карточек ведутся независимо от версии проекта.
