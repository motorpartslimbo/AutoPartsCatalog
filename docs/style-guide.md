# Style Guide

## Общие правила

Все карточки товаров оформляются в едином стиле. Изменения в оформлении предварительно обсуждаются и после утверждения применяются ко всему каталогу.

## Название товара

Формат:

**Тип детали + расположение + бренд + артикул**

Пример:

**Колодки тормозные задние Brembo P 85 083**

## Блок «Бренд / Артикул»

После названия обязательно размещается таблица:

```markdown
| | |
|---|---|
| **Бренд** | Brembo |
| **Артикул** | P 85 083 |
```

## Порядок разделов

1. Описание.
2. Преимущества.
3. Характеристики.
4. Комплектация.
5. Важно.
6. Почему выбирают нас.

## Описание

- Объём: 400–600 символов.
- Простой деловой язык.
- Только подтверждённая информация.
- Без рекламных выражений и субъективных оценок.

## Преимущества

- Не более 7 пунктов.
- Каждый пункт начинается с заглавной буквы.
- Каждый пункт заканчивается точкой.
- Используются только подтверждённые преимущества.

## Характеристики

Характеристики оформляются таблицей. Указываются только сведения, полезные покупателю.

Не используются без практической необходимости:

- WVA;
- EAN;
- внутренние каталожные коды;
- неподтверждённые данные.

## Комплектация

Указывается только фактическое содержимое упаковки производителя.

## Важно

Во всех карточках используются два обязательных пункта:

- Перед покупкой рекомендуется проверить совместимость детали по VIN-коду автомобиля или каталожному номеру производителя.
- Комплектация изделия может незначительно отличаться в зависимости от партии производителя без изменения технических характеристик.

## Почему выбирают нас

Раздел является единым для всех карточек каталога. Его изменение допускается только после общего утверждения.

## Язык оформления

Не используются слова:

- лучший;
- идеальный;
- премиальный;
- высококачественный;
- инновационный;
- максимальный;
- уникальный;

если они не подтверждены производителем и не имеют практической необходимости.

## Источники информации

Приоритет:

1. Официальный сайт производителя.
2. TecDoc.
3. Exist.
4. Emex.
5. Другие проверенные каталоги.

## Проверка карточки

Перед утверждением карточка проверяется на:

- соответствие шаблону;
- достоверность информации;
- единый стиль;
- отсутствие орфографических ошибок.

## Версии

Все карточки оформляются по шаблону v1.0. Изменения стиля допускаются только после согласования.

Если возникает ситуация, не описанная в этом документе, решение принимается один раз, утверждается и затем применяется ко всем последующим карточкам.
