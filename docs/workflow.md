# Workflow

## Создание новой карточки товара

### Шаг 1. Получение исходных данных

Подготовить:

- бренд;
- артикул;
- ссылку на официальный сайт производителя;
- ссылки на Exist и Emex;
- дополнительные источники — при необходимости;
- фотографии товара — при наличии.

### Шаг 2. Проверка информации

Проверить:

- технические характеристики;
- назначение и расположение детали;
- комплектацию;
- преимущества;
- применяемость — при необходимости.

При расхождении сведений приоритет отдаётся официальному сайту производителя.

### Шаг 3. Создание карточки

Для каждого товара создаются:

- `product.md`;
- `kaspi.txt`.

Карточка оформляется строго по утверждённому шаблону.

### Шаг 4. Проверка

Перед утверждением проверить:

- орфографию;
- соответствие шаблону;
- достоверность характеристик;
- соответствие источникам;
- отсутствие рекламных и неподтверждённых формулировок;
- объём описания 400–600 символов.

### Шаг 5. Подготовка изображений

Требования:

- белый фон;
- геометрия детали не изменяется;
- стикер располагается в левом верхнем углу, если он используется;
- обработанные изображения сохраняются в папке `media`;
- исходные изображения сохраняются в папке `source/original`.

### Шаг 6. Сохранение

```text
catalog/
└── Бренд/
    └── Артикул/
        ├── product.md
        ├── kaspi.txt
        ├── media/
        └── source/
```

### Шаг 7. Утверждение

После проверки карточка получает статус **Утверждено** и добавляется в каталог.

- [ ] Проверены дополнительные источники.

- [ ] Проверены характеристики.
- [ ] Проверена комплектация.
- [ ] Подготовлен `product.md`.
- [ ] Подготовлен `kaspi.txt`.
- [ ] Подготовлены изображения или отмечено их отсутствие.
