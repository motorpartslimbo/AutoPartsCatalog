# CARD_CREATION_RULES.md

# Правила создания карточек товаров

Версия: **1.0**

Этот документ является официальным стандартом проекта
**AutoPartsCatalog** и определяет правила подготовки карточек товаров.

------------------------------------------------------------------------

# 1. Основные принципы

-   Использовать только подтверждённую информацию.
-   Не придумывать характеристики.
-   Приоритет имеют официальные каталоги производителя.
-   Все карточки оформляются в едином стиле.

------------------------------------------------------------------------

# 2. Источники информации

Приоритет источников:

1.  Официальный сайт производителя.
2.  Официальные каталоги производителя.
3.  Каталоги крупных поставщиков.
4.  Проверенные интернет-магазины.

Если данные противоречат друг другу, использовать сведения
производителя.

------------------------------------------------------------------------

# 3. Структура карточки

Каждая карточка содержит:

1.  Название товара
2.  Описание
3.  Характеристики
4.  OEM-номера (если подтверждены)
5.  Применяемость (если подтверждена)
6.  Комплектация
7.  Преимущества
8.  О бренде
9.  Почему выбирают нас

------------------------------------------------------------------------

# 4. Правила написания описания

-   Объём 400--600 символов.
-   Деловой стиль.
-   Без рекламных обещаний.
-   Только подтверждённые сведения.

------------------------------------------------------------------------

# 5. Характеристики

Обязательные поля:

-   Бренд
-   Артикул
-   Тип товара
-   Страна бренда
-   Страна производства

Все остальные параметры указываются в разделе **Дополнительные
характеристики**.

------------------------------------------------------------------------

# 6. OEM-номера

Добавляются только при наличии подтверждённых данных.

Если информации нет --- раздел не заполняется.

------------------------------------------------------------------------

# 7. Применяемость

Указываются:

-   марка автомобиля;
-   модель;
-   поколение (если известно);
-   годы выпуска (если известны);
-   двигатель (если подтверждён).

Если достоверной информации нет --- рекомендуется проверка по VIN.

------------------------------------------------------------------------

# 8. Комплектация

Перечисляется только то, что действительно входит в комплект поставки
производителя.

------------------------------------------------------------------------

# 9. Преимущества

Указываются только реальные преимущества товара.

------------------------------------------------------------------------

# 10. О бренде

Краткая нейтральная информация о производителе.

------------------------------------------------------------------------

# 11. Почему выбирают нас

Стандартный блок:

-   Только оригинальная продукция и проверенные поставщики.
-   Проверка товара перед отправкой.
-   Надёжная упаковка.
-   Помощь в подборе по VIN-коду.
-   Консультация специалистов.

------------------------------------------------------------------------

# 12. Фотографии

Исходные изображения:

    source/

Готовые изображения:

    media/

Требования:

-   белый фон;
-   правильная геометрия;
-   без водяных знаков;
-   стикер в верхнем левом углу (если используется);
-   единый стиль оформления.

------------------------------------------------------------------------

# 13. Итог

Каждая новая карточка должна соответствовать этим правилам.

Все изменения стандарта фиксируются в GitHub.
