# AutoPartsCatalog

## Назначение проекта

**AutoPartsCatalog** — структурированный каталог карточек автозапчастей для хранения, редактирования и публикации описаний товаров в интернет-магазинах и на маркетплейсах.

Все карточки создаются по единому утверждённому стандарту, проверяются по официальным и дополнительным источникам и сохраняются в двух вариантах:

- `product.md` — для Visual Studio Code и GitHub;
- `kaspi.txt` — чистый текст для публикации на Kaspi.

---

## Цели проекта

- Создание единого стандарта карточек товаров.
- Хранение карточек в формате Markdown.
- Подготовка готового текста для Kaspi.
- Централизованное хранение изображений и исходных материалов.
- Использование GitHub для контроля версий.

## Источники информации

Приоритет источников:

1. Официальный сайт производителя.
2. TecDoc — при наличии.
3. Exist.
4. Emex.
5. Другие проверенные каталоги.

При расхождении сведений приоритет отдаётся официальному сайту производителя.

---

## Основные правила

- Используется единый шаблон карточки товара.
- В карточках применяется только проверенная информация.
- Не используются рекламные и неподтверждённые формулировки.
- Каждая карточка проходит проверку перед добавлением в каталог.
- Один товар хранится в одной отдельной папке.
- Папки товаров называются по артикулу без пробелов и специальных символов.
