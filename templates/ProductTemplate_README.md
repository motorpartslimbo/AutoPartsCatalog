# ProductTemplate

## Порядок работы

### 1. Добавить товар в stock.xlsx

Заполнить:

- бренд;
- артикул;
- количество;
- закупочную цену;
- продажную цену.

---

### 2. Создать папку товара

- Если бренд отсутствует, скопировать папку `templates/BrandTemplate`.
- Переименовать её в название бренда и переместить в `catalog/`.
- Внутри папки бренда скопировать `ProductTemplate`.
- Переименовать `ProductTemplate` в артикул товара.

---

### 3. Подготовить материалы

- Добавить исходные фотографии в папку `source`.
- Использовать имена `01.jpg`, `02.jpg`, `03.jpg` и далее.
- Заполнить файл `source/links.md`.

---

### 4. Отправить информацию в ChatGPT

Отправить:

- бренд;
- артикул;
- ссылки;
- при необходимости дополнительные сведения и фотографии.

ChatGPT подготовит:

- `product.md`;
- `kaspi.txt`;
- OEM-номера, если они подтверждены;
- применяемость, если она подтверждена.

---

### 5. Завершить карточку

- Добавить `product.md`.
- Добавить `kaspi.txt`.
- Поместить готовые изображения в папку `media`.
- Использовать имена `01.jpg`, `02.jpg`, `03.jpg` и далее.

---

### 6. Синхронизировать GitHub

В GitHub Desktop выполнить:

- Commit;
- Push origin.

---

### 7. Опубликовать в Kaspi

После публикации:

- отметить `Да` в столбце `Kaspi` файла `stock.xlsx`;
- заполнить `Kaspi SKU`, если он присвоен.

---
