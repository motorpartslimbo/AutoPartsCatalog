# ProductTemplate

## Порядок создания новой карточки товара

### 1. Добавить товар в stock.xlsx
Заполнить:
- Бренд
- Артикул
- Количество
- Закупочная цена
- Продажная цена

### 2. Если бренд отсутствует
Скопировать папку `templates/BrandTemplate`, переименовать её в название бренда и поместить в `catalog/`.

### 3. Создать папку товара
Внутри папки бренда скопировать `ProductTemplate` и переименовать её в артикул.

### 4. Добавить исходные фотографии
Поместить фотографии в папку `source/` с именами:
01.jpg
02.jpg
03.jpg

### 5. Заполнить source/links.md
Добавить:
- ссылку производителя;
- ссылки интернет-магазинов;
- дополнительные источники.

### 6. Отправить информацию в ChatGPT
Отправить бренд, артикул и ссылки.

### 7. После утверждения
Добавить:
- product.md
- kaspi.txt

### 8. Добавить готовые фотографии
Поместить их в папку `media/`.

### 9. GitHub Desktop
Commit → Push origin
