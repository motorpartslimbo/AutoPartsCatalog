# ProductTemplate

## Порядок работы

1. Добавить товар в stock.xlsx.
2. При необходимости создать новый бренд из BrandTemplate.
3. Скопировать ProductTemplate.
4. Переименовать папку в артикул.
5. Добавить фотографии в source (01.jpg, 02.jpg...).
6. Заполнить source/links.md.
7. Отправить ChatGPT бренд, артикул и ссылки.
8. Получить:
   - product.md
   - kaspi.txt
   - OEM-номера (если подтверждены)
   - применяемость (если подтверждена)
9. Сохранить product.md и kaspi.txt.
10. Поместить готовые фотографии в media.
11. Commit → Push.
12. После публикации отметить Kaspi и заполнить Kaspi SKU в stock.xlsx.

## Стандарт карточки

1. Название товара
2. Описание
3. Характеристики
4. OEM-номера
5. Применяемость
6. Комплектация
7. Преимущества
8. О бренде
9. Почему выбирают нас
